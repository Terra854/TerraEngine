# Synthetic frame replay comparer protocol

`synthetic-complete-shape.json` is an explicitly synthetic parser template. Its mock roots and callbacks never establish production replay, Vulkan, performance, or installed-runtime acceptance. `TestFrameStageReplayComparison.ps1` materializes fresh files and mock module pins around it; the selftest launches no processes.

Run with the bundled PowerShell runtime:

```powershell
pwsh -NoProfile -File Tests/Tools/CodeQuality/TestFrameStageReplayComparison.ps1
```

An optional absolute `-WorkRoot` must not already exist. The default is a fresh GUID directory under the temporary directory. The script prints its result root and writes every named case plus `result.json` there.

The public comparer requires absolute input paths and a fresh output file:

```powershell
./CompareFrameStageReplay.ps1 -ReferencePath <reference.json> -CandidatePath <candidate.json> -ManifestPath <frame-replay-workloads.json> -ProvenanceJoinPath <trusted-join.json> -OutputPath <fresh-comparison.json> [-SessionMapPath <reviewed-map.json>]
```

The runner-owned join uses `schemaVersion: frame-stage-replay-provenance-v1`, `protocolFixture: false`, and `reference` / `candidate` objects containing `receipt`, `loadedEngine`, `hostExecutable` file pins (`path`, lowercase `sha256`, integer `bytes`), `runNonce`, and `projectRoot`. `controlPathPairs` contains exactly one reviewed pair per `manifest`, `assetManifest`, `projectClosure`, and `projectRoot`, each with absolute `reference` / `candidate` paths. All pinned files must still match. Both control manifests and the project closure must have identical bytes across sides. The ordered controls.resolvedAssetManifests pins must match actual files and match hash/byte order across sides. The first is the explicit assetManifest; additional inputs must occupy the same Build/Assets/.terra-animation-manifests/*.json relative paths beneath the explicitly reviewed project roots. Engine and collector hashes can differ; each must match its own trusted launch. The receipt must attest its engine hash was verified before engine initialization; its expectedEnginePath and expectedEngineSha256 must match the actual module and trusted per-side pin. This join must be authored by the trusted launching runner, never inferred from an untrusted child receipt.

Optional session maps use `schemaVersion: frame-stage-session-map-v1` and `mappings` rows with `laneId`, `domain` (`Renderer` / `Animation`), and canonical positive UInt64 decimal **strings** `reference` / `candidate`. A mapped lane/domain must explicitly include every observed session identity; mappings must be bijective, consistent and used. Mapping applies only to the reviewed renderer root/persistent/dynamic session keys and animation root/specialist sidecar key session paths. Lifecycle and authored identities remain exact.

Both mandatory ordered lanes require valid schedule construction and per-frame plan/summary validity, typed diagnostics without Error severity, a consistent nonempty registered-system list, and all six required producer workload declarations. Faults and omitted workloads may prevent execution; completed non-omitted callbacks must still have actual chronological evidence. Both mandatory ordered lanes must pass their own required scenario predicates and contain actual typed roots, scheduler declarations/results, command receipts and mutation evidence. FullEngine must include its actual public job graph result projection; ProducerBoundaries must leave that field null. Cold/warm controls require their specific topology predicates and nonempty persistent pages; cold controls additionally require zero reused persistent pages in the first measured receipt. No-output requires the specifically observed null renderer root, zero-output diagnostics and protected authored scene inputs for every frame. Producer callback traces are independently joined to each actual scheduler plan: partition pairs, callback thread facts, completion coverage and all dependency ordering must hold before diagnostic observation order can be excluded. Only a prerequisite with actual omitted=true, executionPolicy=Omitted (3), completed=true, zero partitions and no raw callbacks can lack a temporal callback dependency; such entered-dependent edges are separately counted by omittedDependencyCount. Contradictory omission facts reject even on unused nodes. Missing active prerequisites remain failures. Worker-failure additionally requires a failed callback observed off the coordinator thread. Only lane `diagnostic` subtrees are excluded from authoritative equality. Arrays, resource identities, bit words, additional authoritative fields, flushes, phases and lifetime observations compare exactly.

`-ProtocolOnly` requires synthetic receipt/join labels and always returns `replayAcceptance: false`, `gpuAcceptance: false`, and `realProcessesLaunched: false`. Production comparison requires `protocolFixture: false`; successful comparison is only one input to the parent's complete installed replay campaign and does not establish timing or GPU qualification.

Cancellation scenarios join the full first observed command receipt to the first measured frame. Before-exchange producer epoch invalidation requires Rejected (13) with publication generation zero; this is distinct from graph cancellation. After-exchange completion requires Ok (0) at the actual first-frame authority generation. Cache telemetry remains explicitly CountOnlyNoEntryIdentityProof and is never treated as membership restoration. Restart requires the retained initial and immediately pre-shutdown render/animation roots to remain immutable in both lanes. These action facts are validated independently before comparing sides.

The sole invalid-plan allowance is ProducerBoundaries / worker-failure / ordinal zero: invalid and noncompleted plan, valid system schedule, exact ExecutionFailed(8) GeometryRoutePrepare failure signature, actual noncompleted/non-omitted single-partition result, and its failed off-coordinator raw Exit plus required fault predicates. Recovery frames and other lanes/scenarios still require a valid plan. The raw failure metadata is never removed or normalized. Selftests accept -MinimumTests (at least263, default263), enforce the floor before Passed, and include a direct underfloor rejection case without recursively running the matrix.

Only ProducerBoundaries worker-failure qualifies Mixed at FaultFrameBeforeRendererClear / ordinal0, after actual capture/causality settlement and before the mandatory renderer Clear. Positive complete/compact counts must join the first actual animationAdmission; native frame/publication-generation IDs must join that frame's held renderer root, without claiming a fresh fault publication. All three admission snapshots remain present and exact. AfterMeasuredRecoveryFrames telemetry is explicitly nonqualifying and joins the final actual admission; CPU-only recovery after resource retirement is allowed. Other profiles keep their final-frame qualification.

Restart validates shutdown root retirement and context release before the new context and distinct strongly retained publication observations. Fresh full typed roots and exact old/fresh renderer identity records join their native projections; animation establishes a new session. Backend recovery generation numbers may repeat across reinitialization, including renderer session 2 followed by 2. This replaces the former global renderer-session uniqueness assumption, adds no normalization, and makes no cross-instance ABA claim. Both lanes retain all four held-root immutability observations.

Expected worker faults bind the workload descriptor without a partition suffix to WorkerSafe policy and actual off-coordinator partition-zero callbacks; only the first failure resource names the partition job with #0. Eligibility, main-thread exclusion, inline threshold and non-inline/non-fallback result facts must agree. Fault profile nativePublicationGeneration joins root.generation, while nativePublicationReceiptGeneration independently joins the embedded receipt generation, which may legitimately be zero. Both values remain exact.
